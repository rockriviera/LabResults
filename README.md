<div>
  <h1>Lab Results App</h1>
  <p>Full-stack application for displaying patient laboratory results.</p>
</div>

## Prerequisites

- [.NET SDK 10.0+](https://dotnet.microsoft.com/download)
- [Node.js 22.12+](https://nodejs.org/)

---

## Getting Started

### 1. Backend
In the root folder:
```bash
cd LabResults.Backend
dotnet run
```

### 2. Frontend
In the root folder:
```bash
cd LabResults.Frontend
npm install
npm run dev
```

Navigate to the frontend url presented by VITE.
